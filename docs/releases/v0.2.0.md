# v0.2.0 — Provider-neutral chat and embedding foundation

This release marks the completed scope of the current Enterprise AI Toolkit development cycle.

## Included

- provider-independent chat request/response contracts;
- provider-independent `IEmbeddingGenerator`;
- single and multi-input embedding models with stable caller identifiers;
- explicit vector dimensions;
- deterministic SHA-256-derived local embedding generation;
- validation and cancellation tests;
- runnable console sample;
- .NET 8 build/test CI.

## Boundary

This release does not claim to provide a complete RAG framework, vector-store abstraction, production provider packages, document processing, persistence, observability, or deployment guidance.

The repository enters maintenance mode after this release. Broader retrieval/document/provider work is deferred until the toolkit is intentionally resumed.
